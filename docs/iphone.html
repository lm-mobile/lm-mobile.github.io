iPhone and iPad: Safari once per device

Chrome and Brave on iPhone work the same way, but Safari is already on the device and also supports the two-tap shortcut at the bottom of this page.

1

Copy the bookmark link

Did not copy? Show the link
2

Bookmark this page

Tap the Share button (the square with the arrow), then Add Bookmark, then Save.

Phone screenshot slot: the Share sheet with Add Bookmark.
3

Edit the bookmark

Tap the book icon, then Edit at the bottom, then tap the new bookmark. Set the name to LM. In the address field, delete everything and Paste. Tap Done.

Phone screenshot slot: the bookmark edit screen with name LM and the pasted address.
4

Test it

Open www.geoguessr.com, tap the book icon, and tap LM. You can also type LM in the address bar and pick it from the suggestions.

A message "Learnable Meta 0.96 loaded" appears at the bottom, plus a round LM button. Now go to Play.

Optional: two taps from the Share menu

Safari only. After this one-time setup, starting the script is Share, then Learnable Meta.

1

Create a shortcut

Open the Shortcuts app, tap +, tap Add Action, search for Run JavaScript on Web Page and add it.

Phone screenshot slot: the Shortcuts app with the Run JavaScript on Web Page action added.
2

Paste the code

Tap , then delete the example code inside the action and paste.

Show the shortcut code
3

Show it in the Share sheet

Tap the info icon at the bottom, turn on Show in Share Sheet, and name the shortcut Learnable Meta. Done. On geoguessr.com, tap Share, then Learnable Meta.

Phone screenshot slot: the shortcut details with Show in Share Sheet on.
