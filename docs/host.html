Host your own copy

For people who want to run this themselves. You need the project files (worker.js and the docs folder), available on GitHub. Everything is free.

1

Create the relay on Cloudflare

  1. Sign up at dash.cloudflare.com. No card needed. Skip any offer to add a website.
  2. Open Workers & Pages. The first time, pick a workers.dev subdomain. It becomes part of your address.
  3. Press Create, then Start with Hello World. Name it lm-relay. Press Deploy.
  4. Press Edit code. Select everything in the editor and delete it. Paste the contents of worker.js. Press Deploy.
  5. Your relay is at https://lm-relay.YOURNAME.workers.dev.
2

Put the guide website online

Host the docs folder anywhere that serves plain files: GitHub Pages, Cloudflare Pages, Netlify, or your own web space. In docs/config.js, set relay to your relay address.

3

Point the relay at the website

Near the top of worker.js, set SITE_URL to your website address and paste the file into Cloudflare again. Visitors of the relay address are then sent to the guide.

Safety notes

  • The relay only answers pages on geoguessr.com and stores nothing.
  • It refuses to forward personal Learnable Meta tokens, so it is safe to share with other players. Only the map-creator upload feature needs a token. Set FORWARD_AUTHORIZATION to true only on a relay that is yours alone.
  • Cloudflare's free plan allows 100,000 requests a day, far more than a group of players uses.
  • The loader always downloads the current official script from userscript.learnablemeta.com, unchanged.
