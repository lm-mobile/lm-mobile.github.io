Troubleshooting

Most problems are one of these.

Common problems

  • "Open geoguessr.com first": you tapped the bookmark on another site. Open the game first.
  • Nothing happens when tapping the bookmark on Android: start it from the address bar, not from the Bookmarks list. Type LM and tap the starred suggestion.
  • The bookmark opens a blank page or a search: the address was saved without the javascript: part. Edit it and paste the link again, or create it on a computer (see Computer).
  • "Learnable Meta failed to load": the relay or the Learnable Meta site could not be reached. Check the relay status on the home page and try again.
  • Loaded, but no meta after a guess: use the LM button, below.
  • Map not supported: the script only shows metas on Learnable Meta maps. Pick one from learnablemeta.com/maps.

The LM button

The round LM button at the bottom right opens a small menu.

  • Reset Meta Window Layout puts the meta window back in its default place if you dragged it off screen.
  • Check game now re-reads the current game and shows the meta window if a round has just ended.
  • Diagnostics shows what the script saw: the game, whether the result screen was detected, recent events and errors. Tap Copy and paste the text to whoever helps you; it contains no passwords or tokens.
  • Reload page reloads GeoGuessr. The script stops until you tap the bookmark again.

Officially supported alternatives

  • Android: Firefox for Android plus the Tampermonkey add-on, as in Learnable Meta's own Android guide.
  • iPhone and iPad: Safari plus the Tampermonkey app (paid) or the free Userscripts app, as in their iOS guide.
