Android: Chrome or Brave once per device

Works the same in Edge and Samsung Internet. You add one bookmark, named LM, whose address is a small piece of code. Do these steps on the phone or tablet itself.

1

Copy the bookmark link

Tap the button. It says "Copied" when done.

Did not copy? Show the link
2

Bookmark this page

Tap the three dots at the top right, then the star.

Phone screenshot slot: Chrome's three-dot menu with the star highlighted.
3

Open the bookmark for editing

Three dots, then Bookmarks. Find the bookmark you just made, tap the three dots next to it, then Edit.

Phone screenshot slot: the Bookmarks list with the Edit menu open.
4

Rename it and paste the link

Set the name to LM. In the address field, delete everything, long-press and Paste. The address must start with javascript:. Tap the back arrow to save.

Phone screenshot slot: the Edit bookmark screen with name LM and the pasted address.

If Chrome removes the javascript: part when you paste, create the bookmark in Chrome on a computer that is signed in to the same Google account instead (see Computer). It syncs to the phone within a minute.

5

Test it

Open www.geoguessr.com, tap the address bar, type LM, and tap the LM bookmark in the suggestions (it has a star next to it). Do not open it from the Bookmarks list: on Android the bookmark only works from the address bar.

Phone screenshot slot: the address bar with LM typed and the starred suggestion.

A message "Learnable Meta 0.96 loaded" appears at the bottom, plus a round LM button. Now go to Play.
